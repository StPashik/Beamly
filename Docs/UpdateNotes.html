4K/HDR over AirPlay has not been tested on physical receivers. Playback may be unstable or incompatible with some devices or network configurations.

Automatic update checks and a Settings checkbox. Beamly checks for signed updates at startup and periodically while it runs, normally once a day. Automatic checks stay quiet when no newer version is available or the network is unavailable.

The native update window offers Install Update, Remind Me Later, and Skip This Version. Remind Me Later dismisses the window until the next check, including the next launch. Skip This Version suppresses that version in automatic checks; a manual check can still find it.

Settings → Updates → Check for updates automatically is enabled by default. Turning it off disables subsequent automatic checks, and the choice survives relaunches. Manual checks remain available. Downloads and installation require your explicit choice to install; automatic downloads/installs and system profiling remain disabled. Signed feeds, archive verification, and the existing trusted key are retained.

The new setting and explanation are available in all five interface languages. Your queue, history, resume positions, timing corrections, and preferences are preserved. Original videos and subtitles are never changed. FFmpeg and ffprobe remain included for Apple Silicon and Intel.

Startup checking becomes available after upgrading to 1.0.11. Update choices and preference persistence were checked in isolated applications; this does not certify physical AirPlay output. Receiver retesting of the existing reconnection fixes and audio timing correction is still required. Dolby Vision remuxing is not supported. Bitmap subtitles require compatibility conversion; ASS styling is simplified. This community build is ad-hoc signed and is not notarized by Apple. See the full release notes for verification limits.
